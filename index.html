Sobre este controle

Os comandos vão para a TV pela internet, por um endereço secreto que só este celular conhece (veio pelo QR code). Se perder o celular, desconecte todos pela TV: menu Configurações → Desconectar celulares.

Para usar como app: no menu do navegador, Adicionar à tela inicial.

Ligações na TV

Para aparecer “📞 Ligação no celular · Fulano” na TV quando o telefone tocar, use o app MacroDroid (grátis, Play Store):

  1. Nova macro → Gatilho: Chamada recebida (qualquer contato).
  2. Ação: Requisição HTTP → método POST, URL: o endereço copiado abaixo.
  3. Corpo da requisição (texto): {"acao":"ligacao","alvo":"{call_name}"}
  4. Salve. Pronto: com a TV ligada, a ligação aparece por cima de qualquer coisa, até do Xbox.

O endereço é a chave deste controle: não compartilhe. Se vazar, desconecte os celulares pela TV.
